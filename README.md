# Parking Service
Учебный проект Галицких Владимира Романовича. Тема24: автоматизация паркинга.

Состав: docs — документация; db — схема и учебная база; src — расчёт тарифа; tests — проверки; .github — шаблоны обращений и PR.

Стек: Python3, SQLite3; для будущего веб-интерфейса — HTML/CSS/JavaScript и HTTP API. Библиотека sqlite3 входит в Python.

Проверка: python -m unittest discover -s tests
Создание новой базы: sqlite3 parking.sqlite < db/schema.sql
Демонстрационную базу можно открыть любым совместимым SQLite-клиентом.

Тариф округляет положительную длительность вверх до целой единицы. Отрицательная длительность запрещена.
Не включать рабочие пароли и реальные номера автомобилей в репозиторий. .env.example содержит только шаблоны.

План веток: main — проверенные выпуски, feature/* — задачи. Перед слиянием — review и проверки. Защита веток на удалённом хостинге в этом локальном комплекте не настроена.
